# BOOTH 用トップ画像

BOOTH の商品ページに載せるトップ画像の候補を置く。
一覧ではサムネイルが正方形に切り抜かれるため、どの候補も 1:1 で作ってある。

| 候補 | 方向性 |
| --- | --- |
| `out/thumbnail-a.png` | 宇宙。地球の縁と白いリング光を背景に、銀白の商品名 |
| `out/thumbnail-b.png` | 夕暮れの星空。桃と橙と青の空に、針葉樹の影 |
| `out/thumbnail-c.png` | カフェの夜。琥珀の照明とカウンター。商品名に青の差し色 |
| `out/thumbnail-d.png` | 銀白。白地に髪の筋を思わせる斜線と、瞳の青い光 |

どの候補も、一行の説明と商品名と通知 1 つだけで構成する。
VRChat 向けアプリでスキ数の多い商品の多くがこの形をとっている。

配色と背景の題材は、作者が撮った VRChat のスクリーンショットから拾った。
銀白の髪と青い瞳、黒い服に青の差し色、宇宙と地球、夕暮れの星空、カフェの照明である。
アバター、衣装、ワールドの造形はどれも描いていない。他者のアセットを画像に写さないためである。
通知カードは XSOverlay の通知ポップアップ（左上の丸いアイコン、中央寄せのタイトル、区切り線、本文）を模したもので、実際の画面を撮ったものではない。

## 書き出し

`thumbnail.html` が原稿で、`render.mjs` が各候補を 1600x1600 の PNG に書き出す。

```sh
cd booth
npm install
npm run render
```

Playwright が同梱のブラウザを見つけられない環境では、`CHROMIUM_PATH` に Chromium の実行ファイルを渡す。
